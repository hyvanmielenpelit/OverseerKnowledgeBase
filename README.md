# Overseer Knowledge Base

This repository contains the curated reference articles for the Overseer AI.

## Structure

- `Content/`: This directory contains all the Markdown (`.md`) articles that are read by the Overseer's `KnowledgeBaseService`. Subdirectories are supported and act as topic categories.
- `README.md`: This file.
- `.gitignore`: Standard git ignore file.

All files in the `Content/` directory will be periodically reloaded by the Overseer application.
