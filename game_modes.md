#### 1. Gameplay Modes
Two toggles create four combinations:
- **Modern Mode** (default): resurrection on death, save deleted on load
- **Classic Mode**: permadeath, save deleted on load
- **Casual Mode**: resurrection on death, save persists across loads
- **Casual-Classic** (Reloadable): permadeath but save persists (reload-able)

#### 2. Difficulty Levels
There are 7 difficulty levels available when creating a new character, scaling monster difficulty and player starting stats/items.

#### 3. Tournament Mode
- Forces Classic Mode + Expert difficulty (minimum)
- Requires a GnollHack Account

#### 4. How to Change Modes
- Main Menu → toggle mode switches before starting a new game
