#### 1. Save File Basics
- Games auto-save periodically and on exit (Save & Exit)
- In Classic Mode, save files are deleted when loaded (permadeath)
- In Casual Mode, save files persist across loads

#### 2. Save Transfer Between Devices
1. Ensure both devices have a GnollHack Account configured (Settings → Server Posting)
2. On source device: Main Menu → Vault → Save Transfer → set mode to "Upload" → select save → Transfer
3. On target device: Main Menu → Vault → Save Transfer → set mode to "Download" → select save → Transfer
4. Note: transfer is a *move* operation — the save is removed from the source

#### 3. Version Compatibility
- Not all saves are compatible across versions
- Three compatibility groups exist (A, B, C) with specific version ranges

#### 4. Export / Import (Manual Backup)
- Main Menu → About → Manage Files → Export Saved Games (creates a file to save/share)
- Main Menu → About → Manage Files → Import Saved Games (restores from file)
- Also available: Export/Import Replays, Delete Dumplogs, Delete Snapshots

#### 5. Recovering a Corrupted Save
- Try importing from a backup
- If no backup: the save may be unrecoverable
- To prevent: use Save Transfer to keep a cloud copy before risky operations
