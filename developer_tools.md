---
title: Developer Mode & Debugging
summary: Developer Mode features, Wizard Mode, and in-game debugging tools
---

#### 1. Enabling Developer Mode
- Go to Settings → System and toggle **Developer Mode** on.

#### 2. What Developer Mode Unlocks
- **Main Menu**: Adds a Reset button (resets core files), Options button (opens the defaults.gnh editor), and Wizard Mode switch.
- **Settings**: Unlocks Debug Logging, Low-Level Logging, and Debug Post Channel settings.
- **In-Game Menu**: Adds a Developer button that provides tools to export messages, dump frame logs, and force garbage collection.

#### 3. Wizard Mode
- Toggling Wizard Mode grants the player immortality.
- Unlocks special `#wiz` commands for spawning items, monsters, mapping the level, and testing mechanics.
- In Wizard Mode, save files are not deleted when you die or load the game.
- A special status bar symbol indicates when Wizard Mode is active.

> **Wiki:** For Wizard Mode command details, search the wiki for "Overseer References" and see the **developer_tools** section.
