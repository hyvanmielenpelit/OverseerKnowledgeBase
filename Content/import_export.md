---
title: File Management
summary: Exporting, importing, and deleting saves, replays, dumplogs, and snapshots
---

#### 1. Accessing the File Manager
- Go to **Main Menu** → **About** → **Manage Files**

#### 2. Saves
- **Export Saved Games**: Creates a file to backup or share your save manually.
- **Import Saved Games**: Restores a save game from a file.
- **Delete Saved Games**: Permanently removes saves.
- **Convert Backups**: Converts older format backups to the current format.

#### 3. Replays
- **Export Replays**: Saves recorded gameplay to a file.
- **Import Replays**: Loads replay files.
- **Delete Replays**: Removes replay recordings.

#### 4. Dumplogs
- **Export Dumplogs**: Saves text-based character dump files.
- **Delete Dumplogs**: Removes dumplogs.

#### 5. Snapshots
- **Delete Snapshots**: Removes saved in-game screenshots.

#### 6. Pending Tasks
- **Clear Tasks**: Clears stuck or pending upload/download operations (e.g., if a save transfer gets stuck in the queue).
