---
title: Replay System
summary: Recording, playback, upload, sharing, and cloud storage of game replays
---

#### 1. Auto-Recording
- Go to Settings → Replays to toggle auto-record on/off
- You can also set a storage limit for saved replays

#### 2. Viewing Replays
- Access via Vault → Replays → select a replay → Play
- Playback controls include pause, speed, and jumping to a specific turn

#### 3. Storage
- Replays are organized into local, cloud, and downloaded tabs
- Bulk operations (multi-select, delete) are available

#### 4. Uploading
- Select a replay → More → Upload (requires a GnollHack Account)

#### 5. Sharing
- Select a replay → More → Share (uses the platform's native share sheet)
