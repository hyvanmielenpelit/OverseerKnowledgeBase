---
title: Settings Reference
summary: All 16 settings categories and what each option controls
---

1. **General** — GPU Acceleration, Graphics Mode, Map FPS, Screen Resolution & Scale, Dark Mode, Silent Mode, Tournament Mode
2. **Adventuring** — Auto-pickup rules, safe movement options, HP warning threshold
3. **Layout** — Simple Command Layout toggle, context action buttons
4. **Status Bar** — Classic Status Bar toggle, field ordering
5. **Interface** — Grid display, Hit Point Bars, Messages layout, Walk Arrows, Keyboard Shortcuts
6. **Drawing** — Lighter Unlit Areas, Breathing Animations
7. **Format** — Text/number display formatting
8. **Menu Appearance** — Background artwork, font scaling, row padding
9. **Behavior** — Input handling, touch gestures, auto-save
10. **Bar Commands** — Custom quick-action button configuration
11. **Volume** — Master, Music, SFX, Ambient, Voice/Narration sliders
12. **Forum Posting** — Forum username, auto-posting triggers
13. **Server Posting** — Server credentials, URL, verification, account registration
14. **Replays** — Auto-record toggle, storage limit
15. **Overseer** — Server endpoint, AI mode, voice model, privacy consent
16. **System** — Developer Mode, clear cache, reset data, export/import settings

> **Wiki:** For the complete list of every setting and game option with defaults and descriptions, search the wiki for "Overseer References" and see the **settings_reference** section.
