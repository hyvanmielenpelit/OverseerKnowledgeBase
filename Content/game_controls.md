#### 1. Touch Controls (Mobile)
- Tap an adjacent tile to move/attack
- Tap a distant tile in Travel Mode to auto-travel
- Long-press for context menu / far look

#### 2. Stone Buttons (Top Row)
- Menu — opens in-game menu
- Esc — cancels current command or targeting
- Look Mode — tap tiles to examine them
- Travel Mode — tap distant tiles to auto-travel
- Auto-Dig — automatically dig through walls
- Ignore Stopping — ignore monster movement interruptions
- Auto-Center — keep camera centered on player
- Minimap / Zoom toggles

#### 3. Command Button Rows
- Top row: Inventory, Search, Wait, Drop, Chat, Kick, Repeat
- Bottom row: Swap Weapon, Fire, Throw, Cast Spell, Zap Wand, Apply Item, More Commands
- Corner buttons: Stats (abilities), Equipment (worn items)
- "More Commands" opens a searchable catalog of all game commands

#### 4. Keyboard Shortcuts (Desktop)
- Brief overview of common keys (a–z for commands, arrow keys for movement)

#### 5. Customization
- Command Layout: Settings → Layout → Simple Command Layout toggle
- Bar Commands: Settings → Bar Commands for custom quick-action buttons
- Keyboard Shortcuts display: Settings → Interface → Keyboard Shortcuts
- Desktop-specific: right-click and middle-click quick actions
