---
title: Server Account & Online Features
summary: GnollHack Account setup, score posting, forum integration, and leaderboards
---

#### 1. Creating a GnollHack Account
- Go to Settings → Server Posting → tap the registration link
- Fill in registration form on the website
- Return to Settings → Server Posting → enter username and password → tap Verify

#### 2. Score Posting
- Enable Post Top Scores (Settings → Server Posting)
- Deaths and victories are posted automatically when enabled
- View server leaderboards: Vault → Top Scores → Server button

#### 3. Bones Sharing
- Enable Share Bones Files (Settings → Server Posting)
- Your death locations and items become available for other players to find

#### 4. Forum Posting
- Settings → Forum Posting → set forum username
- Configure auto-posting triggers (deaths, victories)

#### 5. Tournament Mode
- Forces on: score posting, bones sharing, replay recording, save file tracking
- Requires GnollHack Account and minimum Expert difficulty
